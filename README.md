# Cosmic Explorer 🚀

An interactive, space-themed website built with vanilla HTML, CSS, and JavaScript.

## Features
- ✨ Animated starfield background (canvas-based)
- 🪐 Interactive planet showcase with hover effects
- 🛰️ Legendary space missions timeline
- 📊 Animated stat counters
- 🎨 Modern gradient styling with smooth scroll reveal animations
- 📱 Fully responsive design

## Tech Stack
- HTML5
- CSS3 (custom properties, animations, flexbox/grid)
- Vanilla JavaScript (Canvas API, Intersection Observer)

## Run Locally
Just open `index.html` in your browser — no build step required!
